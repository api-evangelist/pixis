# Pixis

> Pixis is an AI-powered advertising and marketing platform for consumer brands, built on
> proprietary codeless AI infrastructure that plans, creates, and optimizes digital advertising
> across channels. Its products include Prism (conversational performance-marketing agent),
> Adroom (generative AI creative production), Performance AI, Creative AI and Visibility
> (AI-search presence tracking). Pixis connects to Google, Meta, TikTok and Salesforce to
> automate media buying and creative generation. Backed by SoftBank Vision Fund, with

## Bottom line for an agent

Pixis has **no public developer API**. There is no OpenAPI, no GraphQL schema, no MCP server,
no A2A agent card, no SDK in any package registry, no webhook catalog, no public API reference,
and no public API key issuance. An agent cannot call Pixis programmatically. Pixis is operated
through its web application after a sales conversation.

The one machine-readable contract Pixis does publish is an OpenID Connect discovery document
for **application login**, not for API access.

## What Pixis does publish machine-readably

- [OpenID Connect discovery](https://auth.pixis.ai/.well-known/openid-configuration): OIDC/OAuth 2.0
  metadata for the Pixis login domain (Auth0 custom domain). Issuer `https://auth.pixis.ai/`.
- [OAuth 2.0 authorization server metadata](https://auth.pixis.ai/.well-known/oauth-authorization-server):
  RFC 8414 document, byte-identical to the OIDC discovery response.
- [JSON Web Key Set](https://auth.pixis.ai/.well-known/jwks.json): two RSA (RS256) signing keys.

Authorization code with PKCE (S256) is the flow the Pixis web app uses. `client_credentials`,
device code, token exchange and JWT bearer grants are advertised. The advertised scopes are the
stock OIDC identity claims (`openid`, `profile`, `email`, `offline_access`, and profile claim
scopes) — there are no Pixis resource scopes.

## Live services observed (undocumented, first-party backends)

Recorded for completeness. These are not developer APIs; none is documented and none accepts a
third-party integrator.

- `https://core-performance.pixis.ai/` — Express + express-jwt. Anonymous requests return 401
  `credentials_required`. `GET /health` returns `{"success":true,"message":"Server Running Fine"}`.
- `https://ws.pixis.ai/` — Socket.IO / Engine.IO v4 realtime service. The handshake at
  `/socket.io/?EIO=4&transport=polling` returns 200 with a session id. No channel or event
  catalog is published.
